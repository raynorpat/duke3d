# CMake Build System + SDL2 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the makefiles and Visual Studio projects with one CMake build that compiles and links `duke3d` and the `build` map editor as 64-bit binaries on Windows, macOS and Linux, against SDL2, with a headless smoke test proving the SDL2 driver layer works.

**Architecture:** Vendor icculus's Build engine into `source/build/` and compile it as the `buildengine` static library. audiolib becomes a second static library. Both executables link them. SDL2 comes from `find_package`, falling back to `FetchContent`, behind `duke3d::*` alias targets. The only SDL 1.2 code, `source/build/sdl_driver.c`, is ported by applying a patch that was already built and tested on macOS arm64.

**Tech Stack:** C99, CMake ≥ 3.21 (presets v3), SDL 2.32.10, SDL2_mixer 2.8.1, CTest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-18-cmake-sdl2-design.md`. Read its "Changes since approval" section before starting.

## Global Constraints

- CMake minimum: `cmake_minimum_required(VERSION 3.21)`; presets file `"version": 3`.
- Build engine upstream: `https://github.com/icculus/buildengine`, commit `f3dce0a10bff90e1ed5cf8ec186b3731237a86da`. Vendor exactly these 22 files: `a.c a.h bstub.h build.c build.h cache1d.c cache1d.h display.h doscmpat.h engine.c engine.h engine_protos.h mmulti.c platform.h pragmas.c pragmas.h sdl_driver.c unix_compat.c unix_compat.h win32_compat.h BUILDLIC.TXT LICENSE.md`.
- SDL pins: SDL 2.32.10 (SHA256 `5f5993c530f084535c65a6879e9b26ad441169b3e25d789d83287040a9ca5165`), SDL_mixer 2.8.1 (SHA256 `cb760211b056bfe44f4a1e180cc7cb201137e4d1572f2002cc1be728efd22660`).
- `USE_I386_ASM` is never defined. 64-bit `long` fixes are out of scope: don't change the engine's or game's types.
- The only game-source edit allowed is the include-path rewrite (`"buildengine/` → `"build/`, `"../buildengine/` → `"../build/`).
- Every local change to a file in `source/build/` gets a line in `source/build/VENDORED.md`.
- Keep `source/makefile.dos`, `source/makefile.lnk`, `extras/` and `testdata/` untouched.
- Executables go to `build/bin/` (`build/bin/<Config>/` on multi-config generators). The editor's CMake target is `buildeditor`, with `OUTPUT_NAME build`.
- **Never push or open PRs.** Pushing is the user's decision; ask first (Task 5).
- Commit messages follow `AGENTS.md`: one or two short lines, starting with a subsystem prefix (`build:`, `engine:`, `ci:`), describing what the change does, with **no metadata or trailers**.
- Follow `AGENTS.md`'s other rules too: surgical changes only, and match the existing style.
- Work on branch `cmake-sdl2`; it already exists and holds the spec.

- [ ] **Step 7: Create `cmake/CompileOptions.cmake`.**

```cmake
# Flags and definitions shared by every duke3d target. Link
# duke3d_compile_options to pick them up.

include(CheckCCompilerFlag)

add_library(duke3d_compile_options INTERFACE)

target_compile_definitions(duke3d_compile_options INTERFACE USE_SDL=1)

if(WIN32)
  target_compile_definitions(duke3d_compile_options INTERFACE
    PLATFORM_WIN32=1)
elseif(APPLE)
  target_compile_definitions(duke3d_compile_options INTERFACE
    PLATFORM_UNIX=1 PLATFORM_MACOSX=1)
else()
  target_compile_definitions(duke3d_compile_options INTERFACE
    PLATFORM_UNIX=1)
  if(CMAKE_SYSTEM_NAME STREQUAL "Linux")
    target_compile_definitions(duke3d_compile_options INTERFACE
      USE_EXECINFO=1)
  endif()
endif()

if(MSVC)
  target_compile_definitions(duke3d_compile_options INTERFACE
    _CRT_SECURE_NO_WARNINGS _CRT_NONSTDC_NO_DEPRECATE)
  # /J: char is unsigned, which the game logic assumes.
  target_compile_options(duke3d_compile_options INTERFACE /J /W3 /wd4996)
else()
  # The game logic assumes unsigned char, and the code relies on
  # type-punning that breaks under strict aliasing.
  target_compile_options(duke3d_compile_options INTERFACE
    -funsigned-char -fno-strict-aliasing -W -Wall -Wno-unused)

  # Newer compilers turn these 1990s-isms into hard errors; keep them as
  # warnings so the original code builds unmodified.
  foreach(_flag
      implicit-function-declaration
      implicit-int
      int-conversion
      incompatible-pointer-types
      return-mismatch)
    string(MAKE_C_IDENTIFIER "DUKE3D_HAS_WNO_ERROR_${_flag}" _var)
    check_c_compiler_flag("-Wno-error=${_flag}" ${_var})
    if(${_var})
      target_compile_options(duke3d_compile_options INTERFACE
        "-Wno-error=${_flag}")
    endif()
  endforeach()
endif()

target_compile_features(duke3d_compile_options INTERFACE c_std_99)

# Game-specific definitions, for duke3d and the build editor only.
add_library(duke3d_game_options INTERFACE)
if(DUKE3D_SHAREWARE)
  target_compile_definitions(duke3d_game_options INTERFACE VOLUMEONE)
else()
  target_compile_definitions(duke3d_game_options INTERFACE VOLUMEALL)
endif()
if(DUKE3D_CONTROLS_MENU)
  target_compile_definitions(duke3d_game_options INTERFACE
    CONTROLS_CONFIG_MENU=1)
endif()
```

```c
/*
 * Smoke test for the SDL2 port of sdl_driver.c: brings up the video mode,
 *  sets a palette, pushes frames, pumps events and shuts down. It needs no
 *  game data. Run with SDL_VIDEODRIVER=dummy for headless CI.
 */
#include <stdio.h>
#include <string.h>
#include "platform.h"
#include "build.h"
#include "display.h"
#include "engine.h"

/* Callbacks the game normally provides to the engine. */
static volatile int timer_calls = 0;
void timerhandler(void) { timer_calls++; }
void keyhandler(void) { }
void faketimerhandler(void) { }

int main(int argc, char **argv)
{
    char pal[256 * 4];
    char readback[256 * 4];
    unsigned long start;
    int i;

    _platform_init(argc, argv, "sdl_driver_smoke", "smoke");
    if (_setgamemode(1, 320, 200) != 0)
    {
        fprintf(stderr, "FAIL: _setgamemode(320x200)\n");
        return 1;
    }

    if ((xdim != 320) || (ydim != 200) || (frameplace == 0))
    {
        fprintf(stderr, "FAIL: mode vars xdim=%ld ydim=%ld frameplace=%ld\n",
                (long) xdim, (long) ydim, (long) frameplace);
        return 1;
    }

    for (i = 0; i < 256; i++)  /* BUILD's BGRx format, 0-63 per channel */
    {
        pal[i*4+0] = (char) (i >> 2);          /* blue */
        pal[i*4+1] = (char) (63 - (i >> 2));   /* green */
        pal[i*4+2] = (char) ((i * 7) & 63);    /* red */
        pal[i*4+3] = 0;
    }
    if (VBE_setPalette(0, 256, pal) != 1)
    {
        fprintf(stderr, "FAIL: VBE_setPalette\n");
        return 1;
    }

    memset(readback, 0, sizeof (readback));
    VBE_getPalette(0, 256, readback);
    /*
     * 0-63 -> 0-255 -> 0-63 truncates, so allow off-by-one; a swapped or
     *  dropped channel is off by far more than that.
     */
    for (i = 0; i < 256 * 4; i++)
    {
        int diff = (int) readback[i] - (int) pal[i];
        if ((i % 4 != 3) && ((diff < -1) || (diff > 1)))
        {
            fprintf(stderr, "FAIL: palette entry %d channel %d: wrote %d, read %d\n",
                    i / 4, i % 4, (int) pal[i], (int) readback[i]);
            return 1;
        }
    }

    for (i = 0; i < 30; i++)
    {
        memset((void *) frameplace, i * 8, xdim * ydim);
        _nextpage();
    }
    _handle_events();

    inittimer();
    start = getticks();
    while (getticks() - start < 500)
        _idle();
    uninittimer();

    /* PLATFORM_TIMER_HZ is 100, so ~50 calls in 500ms; SDL2 at 1ms would be ~500. */
    if ((timer_calls < 25) || (timer_calls > 100))
    {
        fprintf(stderr, "FAIL: timer fired %d times in 500ms (expected ~50)\n",
                timer_calls);
        return 1;
    }

    _uninitengine();
    printf("PASS: sdl_driver smoke test\n");
    return 0;
}
```

- **Removed:** `set_splash()` and the PowerPC Gestalt/CoreServices code.
- **Smaller changes:**
  - Windows gets `alloca` from `<malloc.h>` and `S_IRUSR`-style fallbacks, for `screencapture`.
  - `SDL_JoystickNameForIndex` is used, with a NULL guard.
  - SDL version and driver logging use the SDL2 APIs.
