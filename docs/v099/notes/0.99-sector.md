# sector.c (and spawn): 0.99 beta compared with 1.0 shareware

Scope: the 30 sector.c functions of `1.0-sector.md`, plus `spawn` (game.c in our tree,
dispatched here because the lead at `0x25138` is in it). Everything is stated against OUR
1.0 code in `source/sector.c` and `source/game.c`; a 0.99 change sits under
`#if DUKE3D_GAMEVER < GAMEVER_10`, nested in the `< GAMEVER_11` (or `< GAMEVER_13D`)
branch named in each row. Addresses are flat-image addresses (base `0x10000`), beta first,
then 1.0.

## Method

1. **Pairing.** fmatch pairs 28 of the 30 sector.c functions by order or exactly, in the
   same order as 1.0 (`0x45e50`–`0x4b880`). The two it leaves unpaired, callsound and
   check_activator_motion, are the two functions before isadoorwall (`0x45b80`,
   `0x45d10`) and decompile to the same shapes. spawn is `0x228f0` (1.0 `0x17290`): the
   only function holding the `0x25138` lead, the SE jump table and every picnum case.
2. **Global map.** `scratch/t5-sector/gmap.py` aligns every fmap pair (plus the three
   above) and votes 1.0→0.99 data addresses (1519 addresses). `xlat.py` rewrites the 1.0
   Ghidra decompiles into beta addresses, so `diff` of the two decompiles shows only real
   changes plus register naming. `nd.py` is `t4/ndiff.py` with 1.0 globals mapped instead
   of masked and registers dropped. Masked operands were checked one to one through the
   map (sprite, sector, wall, hittype, `ps` bases and every field offset used below).
3. **Picnum trees.** `tree.py` walks a compare tree for every value 0–8191 (`-x` steps over
   lea/imul/mov to other registers, for trees that compute an index mid-way). `cmptree.py`
   maps 1.0 landings through the instruction alignment and folds bare returns. `body.py`
   collects every instruction reachable from each landing pair and diffs them as
   multisets with stack/register noise removed; `sed.py` prints the ordered diff of one
   pair; `se.py` does the same for the 37-entry SE lotag jump table (`0x22858` /
   `0x171f8`). Every non-empty diff below was read in the disassembly.
   Trees walked: checkhitswitch ×3 (+ the inlined isadoorwall), checkhitwall (mirror,
   wall picnum), checkhitsprite (+ the inner TREE/CACTUS weapon trees), spawn (+ the
   inlined wallswitchcheck), badguy (`0x1dca0`).
4. **Map reach.** `tools/mapcount.py` (run with `python3 -I` from `/tmp`, GRP read in
   place) counts the relevant sprites/walls in the beta's E1L1–E1L6.

## Differences: sector.c

**S1. callsound** (`0x45b80`; ours `sector.c:callsound`).
```c
if(T1 == 0) {                      // 0x45bfa-0x45c56
    if(SLT) { spritesound(SLT,whatsprite);
              if(SHT && SLT != SHT) stopsound(SHT); }
    T1 = 1;                        // always
} else {                           // 0x45c65-0x45ce3
    if(SHT > 254) return;          // as 1.0 (SHT < 255)
    if(SHT) spritesound(SHT,whatsprite);
    if( (soundm[SLT]&1) || SHT ) stopsound(SLT);
    T1 = 0;
}
```
Against 1.0: no `(soundm[SLT]&16) == 0` gate (1.0 does nothing at all for such a sound,
not even `T1 = 1`), no `(sector[SECT].lotag&0xff) != 22` test on `T1 = 1`, and no
`SHT != SLT` term in the stop test. The function returns nothing; 1.0 returns `sn`, and
its only < 1.4 reader (operateactivators' `k`) is gone in 0.99 (S9). State: MUSICANDSFX
`T1`, which movefx reads.

**S2. doanimations** (`0x46160`; ours `sector.c:doanimations`). When an animation reaches
its goal, the slot is overwritten by the last one and 0.99 then calls
`callsound(animatesect[i], -1)` with the **new** occupant's sector (`0x46253`–`0x46263`),
not the finished `dasect`, and with no `(sector[dasect].lotag&0xff) != 22` skip. The
18/19 ceiling skip is as ours. (No `stopinterpolation`, render only.) State: `T1` of a
MUSICANDSFX in the wrong sector.

**S3. animatewalls** (`0x46617`). SCREENBREAK6–8 restore their tag only when
`wall.extra` is none of FEMPIC1 (1280), FEMPIC2, FEMPIC3; ours tests 2 and 3. No E1 wall
has extra 1280.

**S4. operatesectors 16/17** (`vel < 0` test `0x47151`; ours `case 16: case 17:`). When
`getanimationgoal(&floorz)` finds a running animation `i`, 0.99 reverses it instead of
ignoring the use:
```c
q = nextsectorneighborz(sn,sptr->floorz,1, animatevel[i] < 0 ? 1 : -1);
if(q == -1) return;
setanimation(sn,&sptr->floorz,sector[q].floorz,sptr->extra);
callsound(sn,ii);
```
The idle path is as ours.

**S5. operatesectors 18/19** (`0x47282`, callsound `0x47312`): the same reversal for the lift
floor, with the ceiling keeping its gap: `setanimation(floorz, f)` and
`setanimation(ceilingz, f + (ceilingz-floorz))`, speed `extra`, then `callsound(sn,ii)`.

**S6. operatesectors 22** (`0x4768d`): ends with `callsound(sn,ii)`, as ours does
`>= GAMEVER_13D`.

**S7. operatesectors 23** (`0x4779c`–`0x477c2`): inside the toggle loop, every matching
SE11 gets `callsound(sn,ii)` (whatsprite `ii`, before `T5 = 1; T4 = -T4`). No `q` latch:
with two door halves callsound toggles the MUSICANDSFX twice.

**S8. operaterespawns** (`0x47a30`; ours `< GAMEVER_13D` branch). For each RESPAWN with
`SLT == low`: `sprite[i].shade = 54` (byte `+0x10`, `0x47a5e`), then always
`j = spawn(i,TRANSPORTERSTAR); sprite[j].z -= 32<<8`. No `monsters_off`, no
`badguypic(SHT)`, no `extra`. The beta's RESPAWN timer is `shade` throughout: spawn sets
`shade = 53` (P1) and movefx (`0x11e90`, actors module) spawns at `shade == 66` and counts
up past 53.

**S9. operateactivators** (`0x47aa0`; ours `sector.c:operateactivators`). One argument
(`low`); callers `activatebysector` (`0x48b06`), checkhitswitch (`0x488e9`) and CON
`activate` (C099-009). ACTIVATORLOCKED always quotes `FTA(4 or 8, &ps[ps_index])` with the
global at `0x109fee` (`0x47b8a`, `0x47bad`), so `activatebysector` now quotes too. The
`k == -1 && (sector lotag&0xff) == 22 → k = callsound(SECT,i)` block is **gone**
(1.0 `0x4c739`). SE31/32 toggle + `callsound(SECT,j)`, SE36 `T1 = 1`, and
`operatesectors(SECT,i)` are as ours.

**S10. checkhitwall, mirror** (`0x48b46`–`0x48b74`): the weapon list is HEAVYHBOMB,
EXPLODINGBARREL, SEENINE, RADIUSEXPLOSION, RPG: **no HYDRENT**.

## Differences: spawn (game.c)

Tree head `0x22cdf` / `0x175f7`; SE switch `0x24fa8`.

**P2. CAMERA1..+4, CAMERAPOLE, GENERICPOLE** (`0x24ecc`): `sp->extra = 0; sp->cstat =

**P3. OCEANSPRITE4** (`0x23d24`): joins the statics above it in our switch:

**P4. WATERDRIP** (`0x246de`–`0x24764`):
