# 0.99 vs 1.0: CON interpreter and runtime differences

I compared `parse` in the beta (`0x30f80`, jump table `0x30db4`, opcodes 2–92) with 1.0's
(`0x34840`, table `0x34670`). Map: `docs/v10-v11/notes/1.0-con-interpreter.md` and
`1.0-con-runtime.md`. Method:
- Both jump tables dumped. They are a bijection (81 distinct targets), so every opcode
  is handled by the same shared or separate code as in 1.0.
- Each handler disassembled with capstone from its target to the next, diffed after
  masking addresses and registers, and its immediates compared.
- Every handler whose code or constants differed was read in the Ghidra decompile and
  checked in the disassembly at the address given.
- The helpers were compared the same way: execute, move, getglobalz, makeitfall, dodge,
  furthestangle, furthestcanseepoint, alterang and getincangle.

The beta compiler inlines `parseifelse` into every `if` handler: true → `insptr += 2`
and `parse()`; false → `insptr = insptr[1]`, and if that word is 10 (`else`),
`insptr += 2` and `parse()`. That is 1.0's `parseifelse` (`0x34640`), so I don't list it
as a difference.

Ledger rows: `C099-009` to `C099-030`.

Beta globals: `insptr` `0x108548`, `g_sp` `0xb0564`, `g_t` `0xb0560`, `g_x` `0xb0568`,
`g_i` `0xb057c`, `g_p` `0xb057e`, `killit_flag` `0x10aef9`. Tables: `sprite[]`
`0x18ce5c`, `sector[]` `0x20515c`, `hittype[]` `0xb8480` (stride `0x47`), `ps[]`
`0xf0f38` (stride `0x33f`), `krand` `0x6151e`.

## Hypotheses

- **`activate` (69)**, handler `0x32021`: `insptr++; operateactivators(*insptr);
  insptr++`. It doesn't touch the script. The beta's `operateactivators` (`0x47aa0`) takes
  only the lotag. It toggles the matching `cyclers[]` entries, then walks the
  ACTIVATOR sprites (statnum 8) with that lotag. Locked sectors give quote 4 or 8 to
  `ps[0x109fee]` (a player index global, not a parameter), and the others get
  `operatesectors`. It ends with `0x47a30(lotag)`. GAME.CON uses `activate` once, in the
  boss's death code. The handler has no crash mechanism of its own. Whether the boss
  death crashes in DOS is left to the playthrough tasks.
- **`shadeto` (65)**, handler `0x33949`: `shade += 2*ksgn(arg - shade)` with byte
  arithmetic, then `insptr += 2`. This is 1.0's.
- **LIZTROOP spawn**, spawn `0x248cc`–`0x24919`: GREENSLIME (`0x942`) gets `extra = 10`;
  then `if (pal == 0) { if LIZTROOP* (0x690–0x692, 0x6b3, 0x6bd, 0x6cd, 0x6d0) pal =
  22; } else extra <<= 1`. The same picnum set and order as 1.0 (`0x192f5`–`0x19342`).
- **RPG smoke**: moveweapons (`0x13e00`) never spawns SMALLSMOKE behind an RPG. Its only
  SMALLSMOKE (`0x919`) spawn is for picnum 2500 in a lotag-2 sector (`0x14489`), as in
  1.0.

`ps+0x322` is written with 1 in about 20 places outside the CON code too, saveplayer
included. It looks like a status-bar redraw flag. That is for the HUD task to confirm.

`ps+0x260` is also set to `totalclock + 32` by quickkill, together with
`pals = 64,64,64`. So in the beta it is a pals expiry time, not 1.0's fade counter.

## Runtime helpers

**execute** (`0x34600`). The statnum-1 sleep countdown is skipped for BOSS1 and 2710
(`0x34763`–`0x3476a`), as in 1.0 (C10-007). **It has no respawn exemptions**: 1.0 also
skips it for a dead badguy when `respawn_monsters == 1`, and for an invisible item when
`respawn_items == 1`. The rest (killit, the bad-sector delete, the action counter, move)
matches.

**getglobalz** (`0x2dc30`). Statnums `{6, 2, 1, 10, 4}`, as in 1.0. A player (statnum 10)
over a badguy with `xrepeat > 24` gets the push `posxv += sin(ang+1536)<<6`,
`posyv += sin(ang+1024)<<6` (`0x2dd20`–`0x2ddb0`), **at any height**: 1.0 also needs
`|s.z - badguy.z| < 0x5400`. The rest matches 1.0.

**move** (`0x305b0`):
- **faceplayersmart (64) exists**, leading by `posxv >> 9` (`0x3077c`–`0x307bf`). 1.0
  has no flag 64 (C10-006).
- No-move path (no move or no flags): it always calls `setsprite(g_i, x, y, z)` and
  returns (`0x30806`). 1.0 skips the call for a live or non-badguy actor that hasn't
  moved from `bposx/bposy`.
- fleeenemy (4096): `dodge`, then `furthestangle(g_i, 4)` (`0x30870`–`0x30881`). 1.0
  uses 3 in single player at skill below 3, otherwise 2.
- Badguy z: no GREENSLIME (`0x938`) exception (1.0 treats it like a non-badguy here).
  For other badguys except `0x758` and `0x974`:
  - When `g_x < 512`, the player's sprite has `xrepeat < 32` and `extra > 0`, and the
    actor's `xrepeat > 32`, it calls **quickkill** (`0x30a03`). quickkill sets pals
    64,64,64, `extra = 0` and `cstat |= 0x8000`, drops the player to `floorz - 0x800`
    and calls `guts(JIBS6, 8)`.
  - When `zvel < 0` and `z - sector.ceilingz < 0x4000`, then `z = ceilingz + 0x4000`
    and `zvel = 0` (`0x30a38`).
  - 1.0 clamps to `floorz` when moving down, and to `getceilzofslope + 0x3800`.
- Close to the player: `g_x < 844` (`0x34c`) and `xrepeat > 16` → `daxvel = -128`
  (1.0: `g_x < 960`, `-(1024 - g_x)`). The player's velocity is zeroed below 256
  (1.0: 512), and otherwise scaled by `0xab00` as in 1.0 (`0x30aa7`–`0x30bd0`).
- Otherwise: `if (count & 1) return`, skip the actor `actorsqu` points at, `daxvel *= 2`.
  1.0 also has the `&3`, `*4` branch when `bposz == z` and multiplayer or skill > 1. The
  beta has no skill branch.
- The random turn on a wall hit (`count & 15 == 2`, krand) skips BOSS1 and BOSS2
  (`0x30c23`–`0x30c6c`). 1.0 has no boss test.

**alterang** (`0x302d0`): `zvel += ((moveptr[1]<<4) - zvel)/5` **always** (1.0 only
when `zvel < 648`). Both `furthestangle` calls pass **3** (`0x3052c`, `0x3057d`); 1.0
passes 2.

**furthestcanseepoint** (`0x30170`): the angle step is always 1024 (`0x3029e`). 1.0 uses
1024 only in single player at skill below 3, and otherwise `2048/(1 + (krand()&1))`,
an extra krand call.

## Same as 1.0

All other opcodes match 1.0 after masking addresses, registers and the `ps[]` stride,
and with `parseifelse` inlined. That covers:
- `addammo`, `ifrnd`, `ifhitweapon`, `action`, `strength`, `shoot`, `sound`, `state`,
  `killit`, `addweapon`, `ai`, `ifdead`, `ifsquished`, `sizeto` (the `abs(j) > 2` gate),
  `{`, `}`, `spawn` (no sector check)
- `move`, the `ifaction` family, `debris`, `pstomp`, `cstat`, `ifmove`, `ifonwater`,
  `ifinwater`, `ifcount`, `resetcount`, `ifactornotstayput`, `hitradius`, `count`,
  `ifactor`, `ifstrength`, `guts`, `ifspawnedby` (owner test included), `wackplayer`
- `ifhitspace`, `ifoutside`, `operate`, `ifinspace`, `ifplayersl` (`ud.multimode`),
  `ifbulletnear`, `spritepal` (`pal = arg` only), `ifpinventory` (items 0–6, 9, 10),
  `cactor`, `ifphealthl`, `quote`, `ifinouterspace`, `ifnotmoving`, `ifhitedge`,
  `rise`, `ifspritepal`, `money`, `soundonce`, `addkills`, `stopsound`
- getincangle, makeitfall, dodge and furthestangle
