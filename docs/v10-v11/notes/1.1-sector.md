# sector.c: 1.1 shareware compared with 1.3D shareware

Scope: everything `docs/v13d/notes/1.3d-sector.md` covers, from `sw11.bin`
(`0x4af80`–`0x51fff`) against `sw13.bin` (`0x4dc40`–`0x54b6f`). fmatch (`fmap11.txt`)
pairs all 30 functions, in the same order. Method as in `1.1-actors.md`: a token diff of
every pair, then the disassembly or decompile for each non-trivial hunk; the picnum trees
of checkhitswitch, checkhitwall and checkhitsprite were walked for every value 0–8191.
Ledger rows are `G11-Snn`. The 1.1 `ps` stride is `0x34e`; `ps` fields are given as
offsets (sub-part 5d maps them). 1.1 globals used below: `ud.coop` `0x130586`,
`ud.lockout` `0x13058e` (by use), `screenpeek` `0x1305f0`, `ud.level_number`
`0x1305ca`, `ud.from_bonus` `0x130538`.

`hitawall` (1.1 `0x3f750`, CLIPMASK1 from Task 4) is a player.c function in 1.3D
(`1.3d-player.md`), so it is left to sub-part 5d. checksectors calls it at `0x514a1` and
`0x51952`.

### cheatkeys (`0x50750`)

Compared at decompile level for the control flow; the inventory and weapon details belong
with the 1.1 `player_struct` map (5d).

- **Aim mode (bit 23).** Each tic the bit is set toggles `ps+0x32f` (aim_mode, per
  `1.1-premap.md`); turning it off sets `ps+0x34d = 9`. 1.3D copies the held bit and sets
  the 9 on release. `0x507a3`–`0x507bc` vs `0x53119`–`0x53132`.
- **Debounce.** The action block runs when `bits >= 0xff` (any bit from 8 up); 1.3D uses
  `bits & 0xfb799f00`, which leaves out look up/down, center, aim, quit and bit 17.
  `0x507c3` vs `0x5315f`.
- **Quick kick (bit 22)** is inside the action block: holstered → `weapon_pos = -9` and
  the holster bit; KNEE in hand → `ps+0x2be = 1`; otherwise `ps+0x302 = curr_weapon`,
  `ps+0x2e0 = 24`, FTA 80, `addweapon(ps, 0)`. 1.3D sets `quick_kick = 14` and FTA 80
  before the block. `0x50e0c` vs `0x53139`.
- **Inventory** cycles 8 items (item 7 is `ps+0x2f8`, quote 87; boots are 8, quote 6).
- **Weapons**: 10 weapons; slot 9 is HANDREMOTE, chosen when the player owns a live
  HEAVYHBOMB.
- Same as 1.3D: holoduke, heat, first aid, jetpack order; the heat `ps+0x2da == 0` gate;
  first aid `firstaid >= need` subtracts; steroids only at 400; 180 turn.
