# premap.c: 1.1 shareware compared with 1.3D shareware

Scope: everything `docs/v13d/notes/1.3d-premap.md` covers, from `sw11.bin`
(`0x47fc0`–`0x4af6c`) against `sw13.bin` (`0x4aa80`–`0x4dc3f`). fmatch pairs all 21
functions by order or exact match (`fmap11.txt`). Each pair was compared by decompile.
prelevel and the switch trees also got the normalized trace diff described in
`1.1-game.md`. Ledger rows are `G11-Pnn`. Global names are listed in `1.1-game.md`, and
the 1.1 `ps` stride is `0x34e`. Field names that need the 1.1 `player_struct` map
(sub-part 5d) are given as `ps+offset`.

## 3. Checked and equivalent

- **setupbackdrop:** the same 8-entry clear, LA/80/84/89 tables and `parallaxyscale`.
- **prelevel:** the same show2d clears, the sector loop (extra 256, lotag 20/22 bit, parallax
  setup with the LA preload, 32767 secret count, -1 exit point), the statnum-0 loop
  (exit-point sprites, CYCLER, GPSPEED), the **two spawn passes** (non-SE14, then SE14),
  the switch-picnum `+1` list, animwalls and mirrors.
- **xyzmirror, vscrn, cacheit** (fmatch exact), cachespritenum, cachegoodsprites (tile
  loads only), genspriteremaps.
- **The enterlevel floor-picnum loop** (200, 859, 1082), the gm logic, the opendemowrite
  condition, `last_level = level+1`, and `FTA(40)` on level 0.
- **krand:** pickrandomspot is still the only krand in the module, and `randomseed = 17`
  is set in resetprestat before the spawn passes.

## 4. Not checked

- The exact names of the `ps` fields resetplayerstats writes (about 75 stores). Values
  match 1.3D where the field can be paired by value; the full map is sub-part 5d's.
- dofrontscreens and waitforeverybody: drawing and network only.
