# CON runtime: 1.1 shareware compared with 1.3D shareware

Task 3 (`1.1-con-interpreter.md`) compared `parse`'s opcode cases. This note covers the rest
of the runtime:
- `execute`
- `move` (the actor movement interpreter)
- the helpers in gamedef.c that `parse` and `move` call: getincangle, getglobalz,
  makeitfall, dodge, furthestangle, furthestcanseepoint, alterang, parseifelse

ifsquished lives in actors.c and is G11-A03 (`1.1-actors.md`).

Addresses are flat image addresses in `sw11.bin` and `sw13.bin` (1.3D shareware). Pairs
come from fmatch order. They were checked with the same normalized token diff as
`1.1-player.md`, and every non-codegen hunk was read in the disassembly. Ledger rows are
`C11-024` to `C11-030`, after Task 3's `C11-*` rows. Move flags are this tree's:
- faceplayer 1, geth 2, getv 4, faceplayerslow 16, spin 32, faceplayersmart 64
- fleeenemy 128, jumptoplayer 257, seekplayer 512, furthestdir 1024, dodgebullet 4096

1.1 globals: `g_sp` `0xd2474`, `g_t` `0xd2470`, `g_i` `0xd248c`, `g_p` `0xd248e`, `g_x`
`0xd247c`, `ud.multimode` `0x13053e`, `ud.player_skill` `0x1305c6`.

## Differences

| Function | 1.1 | 1.3D | Kind | Evidence |
|---|---|---|---|---|
| getglobalz | runs getzrange only for statnums 6, 2, 1, 4. **Players (10) take the sector's ceiling and floor.** `zr` is always 127. When a badguy stands on a badguy (any pal), it is pushed with `xvel = 128`. The player-on-head and own-projectile cases are as in 1.3D | statnums 10, 6, 2, 1, 4; `zr = 4` for projectiles; a badguy on a badguy with `pal != 1` gets `xvel = -256` | state | `0x31bf0`–`0x31dd2`; 1.3D `0x33cc0` |
| dodge | on a threatening projectile: `s->ang = SA + (d < 0 ? 1024 : 0) - 512`, with no krand | `s->ang -= 512 + (krand()&1024)` | state (RNG) | `0x33fd7`–`0x33ff3` |
| furthestangle | a non-player returns `s->ang + 64` whenever `(g_t[0]&63) != 0` | returns `s->ang + 1024` when `(g_t[0]&63) > 2` | state | `0x34056`–`0x34064`; 1.3D `0x36096`–`0x360a9` |
| alterang (seekplayer) | jitter `j = 128 - (krand()&255)` | `128 - (krand()&256)` | state (angle) | `0x344c0`–`0x344d3` |
| move flags | **no spin (32), faceplayerslow (16) or jumptoplayer (257) handling.** New flag **2048**: when the owner is the actor itself, not a badguy, dead or statnum 1024, owner becomes the player. No `hitag == -1 → 0` normalization | the three flags handled; no 2048 | state | `0x345eb`–`0x346dd`; 1.3D bit tests `0x36656`, `0x3668c`, `0x36731` |
| move faceplayersmart | aims at `posx + (posxv >> 12)`, `posy + (posyv >> 12)` | `posxv / 768` | state | `0x34786`–`0x347f0` |
| move dodgebullet | `dodge(g_sp)`, then always `j = furthestangle(g_i, (multimode < 2 && skill < 3) ? 3 : 2)`; `ang = j` when `\|getincangle(ang, j)\| > 128` | `dodge(g_sp)` only | state | `0x3490f`–`0x34974` |
| move z clamps | DRONE (any `extra`): `z` kept 24<<8 above `hittype.floorz` and 32<<8 below `hittype.ceilingz`, with no slope reads and no `zvel` reset. Other flying badguys (not ORGANTIC) going up: ceiling margin `56<<8` from `getceilzofslope`, `zvel = 0` | DRONE/COMMANDER with `extra > 0`: slope floor −30<<8 when falling, ceiling +50<<8 with `zvel = 0`; others `66<<8` and `zvel >>= 1` | state | `0x349cd`–`0x34b4a` |
| move speed | for every badguy (no DRONE, SHARK or COMMANDER exemption) away from the player, moves on every 2nd tic (`<<1`) or every 4th (`<<2`), as in 1.3D. **New:** on tics where `(g_t[0]&15) == 2`, if the last movesprite hit a wall or sprite (`movflag & 0xc000 >= 0x8000`), `ang = krand()&2047` | DRONE, SHARK, COMMANDER move every tic; no random turn | state (RNG) | `0x34cd7`–`0x34dbb` |
| execute | sprite in sector < 0: deleted with no kill credit. The statnum-1 sleep exemption for `xrepeat > 60` tests `picnum == 2630 && picnum == 2710`, which can never be true, so big badguys also fall asleep. The `respawn_items && cstat & 32768` stop applies to badguys too | `sectnum < 0 \|\| >= MAXSECTORS`: badguys add `actors_killed`; badguys with `xrepeat > 60` never sleep | state | `0x38182`; `0x38286`–`0x382e8`; 1.3D `0x3a424`–`0x3a456`, `0x3a54f`–`0x3a558` |

## Same as 1.3D (checked)

- **execute:**
  - insptr starts 4 longs into the actor's script
  - the action-frame counter (lotag += 4, `g_t[2]`/`g_t[3]`)
  - the `killit_flag` delete with the `actorsqu` reset
  - the statnum-6 sleep list (RUBBERCAN, EXPLODINGBARREL, WOODENHORSE, HORSEONSIDE,
    CANWITHSOMETHING, FIREBARREL, NUKEBARREL*, TRIPBOMB, EGG)
- **move:**
  - faceplayer
  - the `g_t[1] == 0 || a == 0` bpos/setsprite exit
  - geth/getv
  - alterang except for players
  - the `±6 → 0` xvel snap
  - APLAYER's ceiling margin
  - the near-player push (`g_x < 960`, posxv friction)
  - movesprite with CLIPMASK0
  - the badguy shade blend and MIRROR delete
- **alterang:**
  - the xvel/zvel easing
  - holoduke targeting
  - `lastvx/lastvy` for players
  - the 19–25 choose window
  - DRONE
  - furthestdir/fleeenemy
- **furthestcanseepoint:** `(g_t[0]&63)` gate; `multimode < 2 && player_skill < 3` → 2
  angles, else `2048/(1+(krand()&1))`. This confirms that `0x13053e` is `ud.multimode`
  (C11-007).
- **makeitfall:** floorspace/ceilingspace gravity.
- **getincangle**, **parseifelse**.
