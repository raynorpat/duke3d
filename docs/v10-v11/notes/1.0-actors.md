# actors.c: 1.0 shareware compared with 1.1 shareware

Scope: the actors.c functions in `1.1-actors.md`, using the `1.0-game.md` method. fmatch
pairs all 28 functions (`sw11.bin` `0x23580`–`0x31b1f`, `sw10.bin` `0x23000`–`0x3133f`);
12 are identical after normalization. 1.0 keeps 1.1's mover source order
(moveeffectors, moveactors, moveexplosions) and its domovethings order. Ledger rows are
`G10-Ann`.

The two `updatesector` rows give the same sector unless sectors overlap at that point.
The transporter case starts from the destination sprite's own sector, so it is the same
in practice. movefta, like the game.c helpers in `1.0-game.md` section 5, passes an
uninitialized start sector to `updatesector`.
