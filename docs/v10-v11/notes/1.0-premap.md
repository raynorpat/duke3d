# premap.c: 1.0 shareware compared with 1.1 shareware

Scope: the premap.c functions in `1.1-premap.md`, using the `1.0-game.md` method. fmatch
pairs all 21 functions (`sw11.bin` `0x47fc0`–`0x4af6c`, `sw10.bin` `0x47580`–`0x4a3c4`).
10 are identical after normalization. Ledger rows are `G10-Pnn`.

## Differences

| Function | 1.1 | 1.0 | Evidence |
|---|---|---|---|
| resetprestat | `gm & MODE_EOL` → HANDREMOTE→HANDBOMB swap; else resetweapons + resetinventory | EOL swap only when `timebeforeexit != 1`. Else resetweapons, then: if `timebeforeexit == 1`, **`gotweapon[1] = 0`, `ammo_amount[1] = 0`, `curr_weapon = 0`** with no resetinventory; otherwise resetinventory. `timebeforeexit = 0` afterwards, as in 1.1 | `0x48750` / `0x47cc0` (`0x47dde`–`0x47e40`) |
| newgame | `ud.last_level = -1` (`0x49c27`); single-player `aim_mode = 0` | sets **`ps[0].last_weapon = -1`** (`0x491a2`) instead, and never resets `last_level`. Only main (`0x1ec3b`), loadplayer (`0x388b5`) and enterlevel (`0x4a357`) write it, so resetpspritevars' first-game colour assignment (`0x493f7`) runs only once per session, and dobonus reads the old value | `0x49bf0` / `0x49180` |
| resetweapons / resetinventory | resetweapons sets `last_weapon = -1` | resetinventory sets it (`0x47c2b`). This matters only where one of the two runs alone: resetprestat's `timebeforeexit == 1` path keeps `last_weapon` | `0x48662` / `0x47c2b` |
| resetplayerstats | clears `aim_mode` (when `last_level == -1` or recstat 2) and, in multiplayer, `no_autoaim`; `cameraclock = totalclock` when `over_shoulder_on` | no aim fields (`reference.md`); `cameraclock = 0` | `0x48230` / `0x477f0` |
| resetpspritevars | saves and restores `aim_mode` | nothing to save | `0x49cb0` / `0x49230` |
| setupbackdrop | `parallaxyscale = 0x8000`, `0x4400` for tile 89 | `0x4400` for every sky | `0x488d0` / `0x47e70` |
| getsound | always caches sounds 189, 232 and 17 on E1L1 | no level test | `0x4a5b0` / `0x49a80` |
| enterlevel | draws displayrooms/displayrest before waitforeverybody; resets the third-person camera clock | neither | `0x4a9e0` / `0x49e90` |
| clearfifo | 1.1 input layout | 1.0 input layout (F10-001) | `0x4a060` / `0x49560` |

The last six rows are aim fields 1.0 doesn't have, render, audio or input format, so
they share one n/a row (G10-P98).
