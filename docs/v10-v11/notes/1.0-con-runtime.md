# CON runtime: 1.0 shareware compared with 1.1 shareware

Scope: the functions in `1.1-con-runtime.md`: execute, move and the gamedef.c helpers.
It uses the `1.0-game.md` method. Task 3 already compared parse's opcodes and the compiler
(`1.0-con-interpreter.md`, `1.0-con-compiler.md`). Ledger rows are `C10-005` to
`C10-008`, after Task 3's C10 rows, as 1.1's runtime rows were C11-024 to C11-031.

1.0 globals: `g_sp` `0xd1fa8`, `g_t` `0xd1fa4`, `g_i` `0xd1fbc`, `g_p` `0xd1fbe`, `g_x`
`0xd1fac`, `ud.multimode` `0x130e97`, `ud.player_skill` `0x130f1f`. These are from the
global vote, and agree with `1.0-con-interpreter.md`.

## Differences

**getglobalz** (`0x31410`):
- The statnum list adds **10 (players)**: `{6, 2, 1, 10, 4}` at `0x3142b`–`0x31442`. 1.1
  has `{6, 2, 1, 4}`, and players take the sector heights (C11-024).
- `zr` is 127 for every statnum, as in 1.1.
- When the `lz` hit is a badguy sprite (`cstat & 48 == 0`):
  - If `s` is a player (statnum 10), the badguy's `xrepeat > 24` and
    `|s.z - badguy.z| < 0x5400`, then `ps[s.yvel].posxv += sintable[(a+512)&2047] << 6`
    and `posyv += sintable[a&2047] << 6`, with `a = badguy.ang + 1024`, and it returns
    (`0x314ec`–`0x315bc`). This is the same push, by the same formula
    (`sin(ang+1536)`, `sin(ang+1024)`), that 1.1 does in processinput (G11-L05,
    `0x450e6`–`0x4512f`). 1.0 does it here instead.
  - Otherwise, any `s` that is not a projectile gets `dispicnum = -4`, `xvel = 128` and
    `ssp`. This is 1.1's rule (C11-024), but in 1.0 it also reaches a player standing
    on a small or distant badguy.
- The APLAYER and projectile-owner rules match 1.1.

The only player path into getglobalz is `fall` (parse `0x3532e`). The 1.0 GAME.CON's
`actor APLAYER` runs `fall` only while the player is dead, so live players never get
the push (G10-L01).

**move** (`0x33e30`):
- **No faceplayersmart (flag 64).** The 1.1 block at `0x34782`–`0x34813` has no 1.0
  counterpart, so the flag does nothing.
- Close to the player, an actor with `xrepeat > 16` and `g_x < 960` (at `>= 512`) scales
  `posxv`/`posyv` by the constant **`0xab00`** (`0x343d5`, `0x34408`). 1.1 uses
  `dukefriction - 0x2000`, which is `0xafd0` with 1.1's USER.CON.
- The rest is 1.1's, including flag 2048, the z clamps and the random turn.

**execute** (`0x377f0`), the statnum-1 sleep test (`0x3795d`–`0x3797c`):
- 1.0 skips the whole sleep block when `picnum == 2630 || picnum == 2710` (BOSS1, and
  2710), whatever the size. So these bosses never fall asleep.
- In 1.1 the test is dead code (`picnum == 2630 && picnum == 2710`, C11-030), so every
  boss can sleep.

## Same in both

The bad-sector delete, the `respawn_items` stop and the rest of execute;
`getincangle`, `makeitfall`, `dodge`, `furthestangle`, `furthestcanseepoint`, `alterang`
and `parseifelse`.
