# sector.c: 1.0 shareware compared with 1.1 shareware

Scope: the sector.c functions in `1.1-sector.md`, using the `1.0-game.md` method. fmatch
pairs all 30 functions in the same order (`sw11.bin` `0x4af80`–`0x51fff`, `sw10.bin`
`0x4a3d0`–`0x5122f`). 23 are identical after normalization, including operatesectors
and every operate* function. The picnum trees of checkhitswitch (three trees) and
checkhitsprite were walked for every value 0–8191. Ledger rows are `G10-Snn`.

## Differences

| Function | 1.1 | 1.0 | Evidence |
|---|---|---|---|
