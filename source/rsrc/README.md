# Windows icons

These unmodified classic icons come from
[JFDuke3D](https://github.com/jonof/jfduke3d/tree/55c5f9592d2a78e427a2bbdb13ce3c4c9ccf6f04/rsrc):

- `duke3d.ico`: upstream `game_icon.ico`.
- `build.ico`: upstream `build_icon.ico`.

The icons retain their upstream ownership and licensing; see JFDuke3D's
[`GPL.TXT`](https://github.com/jonof/jfduke3d/blob/55c5f9592d2a78e427a2bbdb13ce3c4c9ccf6f04/GPL.TXT)
and [`README.md`](https://github.com/jonof/jfduke3d/blob/55c5f9592d2a78e427a2bbdb13ce3c4c9ccf6f04/README.md).

Each Windows executable embeds its icon through a resource file. SDL2
selects the first embedded icon when it registers the window class.
